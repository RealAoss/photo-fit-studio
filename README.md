# Photo Fit Studio

Resize a photo to fit a maximum width and height. Export a JPEG or PNG without uploading the original.

Download `index.html` and open it in your browser. It works offline with no account or installation. Data stays in the open tab. Export or print before closing the tab.

## Example

Choose a 2400 × 1200 photo and set both maximum dimensions to 600. The export is 600 × 300. Smaller originals retain their original size.

## Limitations

Work stays in the browser tab. Save the result before closing or refreshing the page.
